System Specification
ระบบบริหารจัดการแคดดี้ (Caddy Management System : CMS)

Version 1.0

1. วัตถุประสงค์

ระบบบริหารจัดการแคดดี้แบบครบวงจร สำหรับสนามกอล์ฟ รองรับการบริหารคิว การจองแคดดี้ การบันทึกการทำงาน การลา การคำนวณรายได้ การจ่ายเงินรายสัปดาห์ การประเมินผล และ Dashboard สำหรับผู้บริหาร โดยสามารถใช้งานผ่าน Web Browser และอุปกรณ์มือถือได้ทุกที่
